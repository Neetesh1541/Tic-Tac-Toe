# 🎯 Tic-Tac-Toe

> **A polished Python desktop Tic-Tac-Toe game with an unbeatable AI opponent.**

Tic-Tac-Toe is a lightweight desktop game built with **Python and Tkinter**. Play locally with another person or challenge an AI opponent powered by the classic **Minimax algorithm**.

## ✨ Features

- 🎨 Clean dark-themed desktop interface
- 👥 Local two-player mode
- 🤖 Human vs AI mode
- 🧠 Minimax-based AI decision making
- 📊 Live X, O, and draw scoreboard
- 🟢 Clear turn indicator
- 👤 Player-name validation
- 🔄 New-round and score-reset controls

## 🧠 AI Strategy

The AI uses **Minimax** to evaluate possible game states and choose the strongest available move. This makes the AI optimal for the standard Tic-Tac-Toe game.

Detailed implementation notes are available in [`docs/AI.md`](docs/AI.md).

## 🚀 Getting Started

### Run locally

Make sure Python 3 and Tkinter are installed, then run:

```bash
python "tic tac toe.py"
```

No third-party Python package is required beyond the standard Tkinter installation.

## 🎮 Gameplay

Choose your game mode, enter player names when required, and take turns placing your mark. Win by completing a row, column, or diagonal—or finish with a draw if the board is full.

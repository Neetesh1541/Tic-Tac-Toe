# Playing the Game

## Two Players

Enter names for both players, keep **Two Players** selected, and press **Start Game**. X always starts the round.

## Vs AI

Enter the human player's name, select **Vs AI**, and start the game. The human plays X and the AI plays O.

## Controls

- **New Round** clears the board while keeping the score.
- **Reset Scores** clears the scoreboard and starts a fresh round.
- **Change Players** returns to the setup screen.

The application displays a message when a player wins or when the board ends in a draw.
